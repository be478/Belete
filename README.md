# BK Accounting and Tax LLC

Official website project for **BK Accounting and Tax LLC**.

Production domain: `bkaccountingtax.com`

## V1 direction

- Human-centered accounting and tax website
- Astro + TypeScript + Tailwind CSS
- Accessible, responsive, static-first architecture
- Gold / charcoal / ivory visual system
- Microsoft 365 email DNS must remain untouched during deployment

Development work is performed on feature branches and reviewed before merging to `main`.
